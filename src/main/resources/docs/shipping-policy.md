# 배송 규정

## 1. 배송 소요 기간

- 결제 완료 후 평균 **2~3일** 이내 배송됩니다.
- 주말·공휴일은 배송일에서 제외됩니다.
- 도서·산간 지역은 **1~2일**이 추가로 소요됩니다.
- 예약 판매 상품은 상세 페이지에 표기된 출고 예정일을 따릅니다.

**당일 출고 기준**: 평일 **오후 2시 이전** 결제 완료 건에 한합니다.
오후 2시 이후 주문은 다음 영업일 출고됩니다.

## 2. 배송비

| 구분 | 금액 |
|---|---|
| 기본 배송비 | **2,500원** |
| 50,000원 이상 구매 | **무료** |
| 제주도 | 추가 **3,000원** |
| 도서 산간 (울릉도·백령도 등) | 추가 **5,000원** |
| 대형·중량 상품 (가구·가전) | 상품별 별도 표기 |

무료 배송 기준 금액은 **할인·쿠폰 적용 후 실결제 금액**을 기준으로 판단합니다.
포인트 사용액은 결제 금액에 포함하여 계산합니다.

## 3. 배송 조회

- **마이페이지 > 주문내역 > 배송조회**에서 실시간 확인이 가능합니다.
- 배송 시작 시 SMS 또는 카카오 알림톡으로 송장 번호가 발송됩니다.
- 송장 번호 등록 후 택배사 시스템에 반영되기까지 **최대 1~2시간** 걸립니다.
- 상담 챗봇에 주문번호를 알려 주시면 현재 상태를 바로 조회해 드립니다.

## 4. 배송 상태 안내

| 상태 | 의미 |
|---|---|
| 결제완료 | 주문이 접수되었고 출고 대기 중 |
| 상품준비중 | 창고에서 상품을 포장하는 단계 |
| 배송중 | 택배사가 상품을 인수해 이동 중 |
| 배송완료 | 수령지에 전달 완료 |

## 5. 배송 업체

- CJ대한통운, 한진택배를 통해 배송됩니다.
- 대형 가구·가전은 자체 배송 또는 전문 설치 기사가 방문합니다.
- 택배사 지정은 불가하며, 지역에 따라 자동 배정됩니다.

## 6. 묶음 배송

- **동일 판매자**의 상품을 함께 주문하면 묶음 배송되어 배송비가 한 번만 부과됩니다.
- 서로 다른 판매자의 상품은 개별 배송되며 배송비가 각각 부과됩니다.
- 출고일이 다른 상품을 함께 주문하면 **가장 늦은 상품 기준**으로 일괄 출고됩니다.
  먼저 받기를 원하시면 주문을 나누어 주세요.

## 7. 부재 및 주소 변경

- 부재 시 택배 기사가 문 앞 보관 또는 경비실 위탁 후 안내 문자를 보냅니다.
- 배송지 변경은 **상품준비중 단계까지만** 가능합니다.
  배송중으로 바뀐 뒤에는 변경할 수 없습니다.
- 주소 변경은 마이페이지 > 주문내역 > 배송지 변경에서 신청합니다.

## 8. 분실·파손

- 배송 중 분실이 확인되면 **재배송 또는 전액 환불** 중 선택할 수 있습니다.
- 파손 상품은 수령 후 **48시간 이내** 사진과 함께 접수해 주셔야 합니다.
- 문 앞 보관을 요청하신 뒤 발생한 분실은 보상이 제한될 수 있습니다.

## 9. 해외 배송

- 현재 해외 배송은 지원하지 않습니다.
- 배송대행지(배대지) 주소로는 발송 가능하나, 이후 발생한 문제는 보상 대상이 아닙니다.
