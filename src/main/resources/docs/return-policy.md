# 반품·교환·환불 규정

## 1. 반품 신청 기간

- 단순 변심: 상품 수령일로부터 **7일 이내**
- 상품 불량·오배송: 수령일로부터 **30일 이내**
- 표시·광고와 다른 상품: 사실을 안 날로부터 **30일 이내**, 수령일로부터 3개월 이내

## 2. 반품 배송비

| 사유 | 부담 주체 | 금액 |
|---|---|---|
| 단순 변심 | 고객 | 왕복 **5,000원** (편도 2,500원) |
| 상품 불량·파손 | 회사 | 0원 |
| 오배송 | 회사 | 0원 |
| 제주·도서 산간 단순 변심 | 고객 | 왕복 **11,000원** |

반품 배송비는 환불 금액에서 차감됩니다. 별도 입금은 필요하지 않습니다.

## 3. 교환 규정

- **불량·하자·파손**이 확인된 경우 무상 교환이 가능합니다.
- 교환 신청은 수령일로부터 **14일 이내**에 접수해야 합니다.
- 색상·사이즈 변경은 단순 변심으로 분류되어 왕복 배송비가 부과됩니다.
- 동일 상품 재고가 없으면 교환 대신 환불로 자동 전환됩니다.
- 교환은 **주문당 1회**만 가능합니다. 두 번째부터는 반품 후 재주문해 주셔야 합니다.

## 4. 반품·교환 불가 사유

- 고객의 사용 또는 훼손으로 상품 가치가 현저히 감소한 경우
- 포장을 개봉하여 상품 가치가 훼손된 경우 (식품·화장품·속옷·이어폰 등 위생 관련 상품)
- 시간 경과로 재판매가 곤란한 경우
- 고객의 주문으로 개별 제작된 맞춤 상품
- 디지털 콘텐츠의 다운로드 또는 시리얼 번호가 발급된 경우

## 5. 부분 반품

- 한 주문에 여러 상품이 있으면 **일부만 반품**할 수 있습니다.
- 부분 반품으로 남은 금액이 무료 배송 기준(50,000원) 아래로 내려가면,
  기본 배송비 **2,500원**이 환불액에서 추가 차감됩니다.

## 6. 환불 처리 기간

| 결제 수단 | 소요 기간 | 기준 시점 |
|---|---|---|
| 신용·체크카드 | **3~5 영업일** | 반품 검수 완료 후 승인 취소 |
| 계좌이체·무통장 | **1~2 영업일** | 검수 완료 후 등록 계좌로 입금 |
| 포인트 | **즉시** | 취소와 동시에 복원 |
| 간편결제(카카오페이·네이버페이) | **2~4 영업일** | 각 사 정책에 따름 |

카드 취소는 카드사 정산 주기에 따라 명세서에 반영되는 시점이 다를 수 있습니다.

## 7. 반품 신청 방법

1. **마이페이지 > 주문내역 > 반품/교환 신청**
2. 사유 선택 후 사진 첨부 (불량·파손인 경우 필수)
3. 회수 방문일 지정 — 신청일 기준 **1~2일 내** 택배 기사 방문
4. 검수 완료 후 환불 진행

상담 챗봇에서 "환불 접수해 주세요"라고 요청하면 티켓이 생성되며,
담당자 승인 후 처리됩니다. **접수 즉시 환불되지는 않습니다.**
