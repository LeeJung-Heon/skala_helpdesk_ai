# 고객센터 이용 안내

## 1. 운영 시간

| 채널 | 운영 시간 |
|---|---|
| 전화 상담 | 평일 **09:00 ~ 18:00** (점심 12:00~13:00 제외) |
| 1:1 문의 게시판 | 24시간 접수 · **영업일 기준 1일 이내** 답변 |
| 챗봇 상담 | **24시간** |
| 카카오톡 채널 | 평일 09:00 ~ 18:00 |

주말과 공휴일에는 전화 상담을 운영하지 않습니다.
챗봇은 언제든 이용할 수 있으며, 처리에 사람이 필요한 요청은 티켓으로 접수됩니다.

## 2. 문의 유형별 처리 시간

| 유형 | 처리 기준 |
|---|---|
| 배송 조회 | 즉시 (챗봇에서 주문번호로 조회) |
| 환불·교환 접수 | 접수 즉시 · 담당자 승인 **1영업일** 이내 |
| A/S 진단 | 입고 후 **2~3일** |
| 결제 오류 확인 | **1영업일** 이내 |
| 개인정보 열람·삭제 | **10일** 이내 (법정 기한) |

## 3. 챗봇으로 할 수 있는 일

- 사내 규정 안내 (반품·배송·회원·결제·A/S)
- **본인 주문**의 배송 상태 조회
- 환불 티켓 접수

챗봇은 **본인 주문만** 조회할 수 있습니다. 다른 사람의 주문번호를 입력해도
조회되지 않으며, 이는 정상 동작입니다.

## 4. 챗봇이 처리하지 못하는 일

- 환불의 **실제 실행** (접수까지만 가능하며 담당자 승인이 필요합니다)
- 주문 취소 (마이페이지에서 직접 처리)
- 배송지 변경
- 다른 고객의 정보 조회

이 경우 1:1 문의 또는 전화 상담을 이용해 주세요.

## 5. 에스컬레이션 기준

- 동일 문의가 **3회 이상** 반복되면 전담 상담원에게 이관됩니다.
- 결제 금액 오류, 개인정보 유출 의심은 **즉시** 상급 담당자에게 이관됩니다.
- VIP 등급 회원은 1:1 전용 상담 채널을 이용할 수 있습니다.
