# A/S 및 품질보증 규정

## 1. 무상 보증 기간

| 상품군 | 무상 보증 기간 |
|---|---|
| 전자제품 (이어폰·키보드·스탠드 등) | 구매일로부터 **1년** |
| 배터리 내장 제품의 배터리 | **6개월** |
| 액세서리·케이블 | **6개월** |
| 소모품 (필터·이어팁 등) | 보증 대상 아님 |

보증 기간은 **구매일 기준**이며, 주문내역에서 확인할 수 있습니다.

## 2. 무상 A/S 대상

- 정상적인 사용 중 발생한 제조상 결함
- 구매 후 **7일 이내** 발견된 초기 불량 (이 경우 A/S 대신 교환·환불 선택 가능)
- 동일 증상으로 **2회 이상** 수리했으나 재발한 경우 (교환 또는 환불로 전환)

## 3. 유상 처리 대상

- 고객 부주의로 인한 파손·침수·낙하
- 사설 업체에서 임의로 분해·수리한 이력이 있는 경우
- 보증 기간이 지난 경우
- 정품 등록 스티커가 훼손되어 확인이 불가한 경우

유상 수리는 **견적 안내 후 동의를 받고** 진행합니다. 동의 없이 수리하지 않습니다.

## 4. A/S 접수 방법

1. **마이페이지 > 주문내역 > A/S 신청**
2. 증상과 사진을 첨부 (영상 첨부 시 진단이 빨라집니다)
3. 회수 택배 방문 — 접수일 기준 **1~2일 내**
4. 입고 후 진단 **2~3일**, 수리 완료까지 평균 **7~10일**

## 5. A/S 배송비

- 무상 보증 기간 내: **회사 부담**
- 보증 기간 경과 또는 유상 처리: **고객 부담** (왕복 5,000원)
- 진단 결과 이상이 없는 경우: 고객 부담

## 6. 부품 보유 기간

- 전자제품 핵심 부품은 단종 후 **4년**까지 보유합니다.
- 부품이 없어 수리가 불가하면 감가상각 후 환불 또는 동급 상품으로 교환합니다.

## 7. 반품과 A/S 구분

수령 후 **7일 이내**의 불량은 **반품·교환**이 더 빠릅니다.
7일이 지난 뒤의 불량은 **A/S** 절차를 따릅니다.
어느 쪽인지 판단이 어려우면 상담 챗봇에 주문번호와 증상을 알려 주세요.
