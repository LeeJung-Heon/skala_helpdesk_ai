# 결제 및 증빙 규정

## 1. 결제 수단

- 신용·체크카드 (국내 모든 카드사)
- 계좌이체 및 무통장 입금
- 간편결제: 카카오페이, 네이버페이, 토스페이
- 휴대폰 소액결제 (월 한도 50만 원)
- 포인트 (상품 금액의 최대 30%)

**해외 발행 카드는 지원하지 않습니다.**

## 2. 무이자 할부

- 5만 원 이상 결제 시 카드사별 무이자 할부가 적용됩니다.
- 무이자 개월 수는 카드사 프로모션에 따라 매월 달라집니다.
- 결제 페이지 하단에서 당월 적용 카드사를 확인할 수 있습니다.
- 부분 취소 시 할부는 자동으로 재계산됩니다.

## 3. 무통장 입금

- 주문 후 **48시간 이내** 입금하지 않으면 주문이 자동 취소됩니다.
- 입금자명이 주문자명과 다르면 확인이 지연될 수 있습니다.
- 입금 확인은 평일 기준 **1시간 이내** 자동 처리됩니다.

## 4. 주문 취소

| 시점 | 가능 여부 | 방법 |
|---|---|---|
| 결제완료 | 즉시 취소 가능 | 마이페이지에서 직접 |
| 상품준비중 | 취소 가능 | 마이페이지에서 직접 |
| 배송중 | **취소 불가** | 수령 후 반품으로 처리 |
| 배송완료 | **취소 불가** | 반품 규정에 따름 |

배송중 이후에는 취소 대신 반품 절차를 따르며, 이 경우 반품 배송비가 발생합니다.

## 5. 영수증과 증빙

- **현금영수증**: 무통장 입금 시 마이페이지에서 신청 (결제일로부터 90일 이내)
- **세금계산서**: 사업자 회원만 신청 가능, 매월 말일 일괄 발행
- **카드 매출전표**: 마이페이지 > 주문내역에서 즉시 출력
- 현금영수증과 세금계산서는 **중복 발행되지 않습니다.**

## 6. 결제 오류

- 결제가 중복 승인되면 **자동으로 취소**되며 3~5 영업일 내 환불됩니다.
- 결제 실패가 반복되면 카드사 한도 또는 해외 결제 차단 설정을 확인해 주세요.
- 승인은 되었는데 주문이 생성되지 않은 경우 고객센터로 문의해 주시면
  즉시 확인 후 처리해 드립니다.
